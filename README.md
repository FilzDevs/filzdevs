### 🖨️ PRINTBOARD
**Your 3D Printer Farm. One Dashboard.**

[![PrintBoard](https://github-readme-stats.vercel.app/api/pin/?username=FilzDevs&repo=PrintBoard&theme=tokyonight&hide_border=true)](https://github.com/FilzDevs/PrintBoard)

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Qt](https://img.shields.io/badge/PySide6-41CD52?style=for-the-badge&logo=qt&logoColor=white)
![Linux](https://img.shields.io/badge/Linux-FCC624?style=for-the-badge&logo=linux&logoColor=black)
![Klipper](https://img.shields.io/badge/Klipper-Moonraker-00d9ff?style=for-the-badge)

A native desktop application for managing Klipper/Moonraker 3D printers.

- 🖨️ Multi-printer dashboard
- 🌡️ Live temperatures and print progress
- 🔔 Desktop, Telegram and Discord notifications
- 📊 Print history and statistics
- 💰 Filament cost calculator
- 📁 Model library and G-code uploads
- 🔒 Read-only by default

**Current version:** `v0.2.0` — Development / Testing
